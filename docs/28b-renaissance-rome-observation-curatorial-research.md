## 1. 罗马工作坊：一位大师，其实有多少双手？

核心问题：

> 罗马怎样把大师之间的竞争，变成纸上试验、团队协作和传遍欧洲的风格？

四幕因果链：

1. **先在纸上试错**：米开朗琪罗《利比亚女先知习作》与拉斐尔《圣婴习作》让修改、局部研究和转印痕迹可见；
2. **把图样放大成共同语言**：拉斐尔《捕鱼奇迹》挂毯画稿把构图变成布鲁塞尔织工可以执行的跨城市指令；
3. **大师的名字，装着很多双手**：《米尔维安大桥之战》显示拉斐尔去世后工作坊如何继续大型宫殿工程；
4. **版画让风格跑得比人更快**：马坎托尼奥·雷蒙迪据拉斐尔设计刻制的《帕里斯的评判》把风格复制并传播到更多工坊与城市。

离场结论：大师既是创作者，也是组织者；竞争改变了试错、协作和传播的方式，却也让许多双手藏进一个签名。

主要来源：

- [The Met — Studies for the Libyan Sibyl](https://www.metmuseum.org/art/collection/search/337497)
- [The Met — Studies of the Christ Child](https://www.metmuseum.org/art/collection/search/340579)
- [V&A — The Raphael Cartoons](https://www.vam.ac.uk/articles/the-raphael-cartoons)
- [Vatican Museums — Hall of Constantine](https://www.museivaticani.va/content/museivaticani/en/collezioni/musei/stanze-di-raffaello/sala-di-costantino.html)
- [The Met — The Judgment of Paris](https://www.metmuseum.org/art/collection/search/337058)

内容边界：

- 不把拉斐尔与米开朗琪罗的私人敌意写成已证实的单线冲突；
- 《米尔维安大桥之战》的具体分工标为研究判断，不假装每一笔归属都已确定；
- “工作坊”同时表示学习、分工、质量控制和品牌延续，不把助手贬低为机械执行者。

## 2. 望远镜与星图：新宇宙如何成为证据？

核心问题：

> 一张新宇宙图、更精确的数字和一根望远镜，怎样从“新想法”变成能被别人检查的证据？

四幕因果链：

1. **先换一张宇宙图**：1543 年《天体运行论》日心秩序图重新安排地球的位置，但图本身仍是待检验的模型；
2. **数字逼圆让路**：第谷的大型象限仪提高肉眼观测精度；开普勒用火星数据比较模型，并最终放弃完美圆形；
3. **把天空送进镜筒**：伽利略望远镜与《星际信使》木星卫星记录说明工具、连续记录和可重复观察必须配套；
4. **证据走进公开争论**：1632 年《关于两大世界体系的对话》把模型、证据、修辞和制度风险带进公共空间。

离场结论：新宇宙不是被一根望远镜突然证明的；模型、精密数据、观察记录、印刷传播和公开争论共同改变了可信的标准。

主要来源：

- [Smithsonian Libraries — Copernicus](https://library.si.edu/digital-library/author/copernicus-nicolaus)
- [Smithsonian Libraries — Tycho Brahe, Mechanica](https://library.si.edu/digital-library/book/tychonisbraheas00braha)
- [Smithsonian Libraries — Kepler, Astronomia nova](https://library.si.edu/digital-library/book/astronomianovaa00kepl)
- [Museo Galileo — Galileo's telescope, Inv. 2428](https://catalogue.museogalileo.it/gallery/GalileosTelescope_n03.html)
- [Smithsonian Libraries — Sidereus nuncius](https://library.si.edu/digital-library/book/sidereusnuncius00gali)
- [The Met — Frontispiece for Dialogo](https://www.metmuseum.org/art/collection/search/377632)

内容边界：

- 明确写出望远镜现象挑战旧宇宙图景，但没有单独证明地球运动；
- 不把哥白尼、第谷、开普勒与伽利略压缩为完全一致的“日心说阵营”；
- 区分“看见现象”“记录变化”“解释现象”与“公开说服”四个不同步骤；
- 开普勒展品使用原书中的模型比较页，不用现代示意图冒充原始史料。

## 3. 视觉与许可策略

- 两厅各使用一张独立生成的 16:9 虚构入口环境，均标为 `decorative_illustration`；
- 馆藏图使用 The Met Open Access、Public Domain 原书扫描或明确 CC BY-SA 摄影；
- 所有图像本地化为 WebP，作品仍保留官方馆藏来源与独立图像来源；
- 入口图不承担史实证明，真实作品图不加统一生成式滤镜；
- 图片失败时，四幕、展签、观察提示、来源和人物导览仍可使用。

- 罗马厅：拉斐尔 / 米开朗琪罗；
- 天文厅：伽利略 / 开普勒；
- 人物只改变观察角度和语言风格，不改变展品、事实、路线或完成条件；
- 中段换人统一称为“另一位同行者”，不假设所有展厅人物都是艺术家；
- 规则降级分别保留构图协作、材料劳动、重复观察与数据偏差四种人物视角。
