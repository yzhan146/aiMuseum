# AI Museum 公开知识与运营指标 — Stage 1 Outcome Definition

> 状态：Stage 1 已批准（2026-07-29）
> 日期：2026-07-29
> 已批准方向：优先建立公开、可信、可抓取的知识层；完整游客模式不进入本次 MVP。

## 1. 目标

让 AI Museum 的人物、时期、展厅和产品方法成为无需登录即可访问、可被搜索与答案系统发现和引用的公开内容，并能观测这些曝光是否带来注册和真实产品使用。

## 2. 用户与场景

- 从 Google、Bing、ChatGPT、Copilot 或外部链接进入的人，希望先获得一个可靠答案，再决定是否注册。
- 教师、家长和历史爱好者希望理解人物资料的来源、AI 演绎边界、儿童安全和长期记忆语义。
- 运营者需要查看注册总量、近期新增、实时在线与活跃趋势，但不能接触用户私人内容。
- 已登录用户继续使用现有博物馆、人物对话、关系、记忆和收藏功能。

## 3. MVP 范围

### 3.1 公开知识层

- 公开首页与“如何运作”页面；
- 3 个时期、9 个展厅、36 位历史人物的独立永久 URL；
- 服务端输出完整正文、语义化内部链接、唯一 metadata 与 canonical；
- 人物页包含生平、影响、作品、关联人物、可探索问题、AI 演绎边界和公开来源；
- `sitemap.xml`、`robots.txt`、适用的 JSON-LD；
- 允许公开搜索爬虫访问，账户、API、对话和个人数据页面不进入索引；
- 公开页面只读取版本化馆藏数据，不创建用户身份、不写进度、不调用模型。

### 3.2 运营指标

- 注册账户总数：已验证、未删除、非测试账户；
- 当前在线：最近 2 分钟内有有效活动的独立登录用户；
- 今日、7 日、30 日新增与活跃；
- heartbeat 每 60 秒一次，隐藏页面暂停，多标签和多设备按用户去重；
- 内部管理员页显示精确指标；
- 公开在线组件只返回聚合区间，少于 10 人不显示，且受配置开关控制。

## 4. 非目标

- 不开放无需登录的模型对话；
- 不建立持久化游客身份、游客收藏、游客关系或游客进度；
- 不引入 Redis、WebSocket 或秒级 presence；
- 不把 FAQ、结构化数据、`llms.txt` 或关键词堆叠当作排名捷径；
- 不公开精确注册总数、用户列表、私人对话或行为明细；
- 不伪造、随机放大或人工修饰在线人数。

## 5. 成功标准

1. 所有公开 URL 无 Cookie、无登录即可返回 200，初始 HTML 含有主体内容。
2. 每个公开实体有唯一可分享 URL、canonical、标题、描述和可抓取内部链接。
3. sitemap 只包含公开 canonical URL；robots 明确保护私人和写接口区域。
4. 公开页面请求不会创建用户数据、调用模型或改变馆藏状态。
5. heartbeat 只能更新当前有效 Session，不能由客户端指定用户。
6. 在线统计按独立账户去重并在 2 分钟无活动后自然退出。
7. 管理员指标要求已登录且在服务端 allowlist 中；普通用户与匿名请求均被拒绝。
8. 公开在线数字经过门槛与分桶，精确数字只在管理员页出现。
9. 自动化测试、类型检查和生产构建通过；关键公开旅程通过真实浏览器验收。

## 6. 观测指标

- Search Console：索引覆盖、曝光、查询和点击；
- Bing Webmaster：索引与 AI citation/grounding query；
- 引荐：搜索、`utm_source=chatgpt.com` 和其他来源；
- 产品漏斗：公开内容访问 → 注册 → 邮箱验证 → 首次人物对话；
- 运营：注册总量、在线、DAU、7 日活跃与近期新增。

## 7. 风险与原则

- “能抓取”不保证被索引或引用，内容独特性与外部权威信号需要长期建设。
- 早期公开在线人数可能形成负面社交证明，因此默认关闭，并在达到门槛后再开启。
- 当前人物包的部分来源仍是通用 biography 索引；页面必须如实展示来源质量，不夸大审核程度。
- AEO/GEO 内容首先服务真人，不批量制造近似问题页。
