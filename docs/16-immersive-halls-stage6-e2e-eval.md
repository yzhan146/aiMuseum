## 2. Browser E2E

测试闭环：

```text
视觉模式 → 主页 → 探索 → 时期馆 → 展厅入口
→ 核心物件 → 展签 → 人物关系 → 关系/时间线
→ 返回展厅 → 人物相遇 → 返回展厅 → 离场问题
```

检查项：

- 9/9 展厅 API 200；每厅 4 个站点；`sceneRef=1.0.0`；场景 WebP 200；
- 新轻快版预览图实际启用，典藏版保持历史重建视觉；
- 1440×1000 与 390×844 页面无遮挡、无破图、无 console error；
- `prefers-reduced-motion: reduce` 下可完成全流程；
- 场景图被阻断时，标题、问题、路线和主要动作仍存在；
- 移动专注页面不显示重复固定底栏；
- 访问进度快速写入串行化，服务端处理跨客户端 revision 冲突；
- 展签明确显示“艺术重建 · 不冒充真实文物”。
